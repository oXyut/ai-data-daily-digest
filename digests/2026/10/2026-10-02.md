## 1. GitHub Copilot：旧モデル4種を非推奨化

- **公開日:** 2026-10-02（GitHub Changelog）
- **タグ:** `generative-ai` `developer-tools` `copilot` `model-lifecycle`
- **日本語サマリ:** GitHubは、Copilot Chat、inline edits、ask／agent mode、code completionを含むCopilot全体でGemini 3.5 Flash、Gemini 3.6 Flash、Kimi K2.7 Code、Claude Opus 4.7を非推奨化しました。代替としてGemini 3.8 Flash、Kimi K3、Claude Opus 5.5を案内しています。
- **なぜ重要か:** 特定モデルを前提にしたプロンプト、評価、社内手順、Enterpriseのモデルポリシーは、可用性と出力差を見込んだ移行確認が必要です。モデル名を固定する自動化では特に影響が明確です。
- **限界:** GitHubは代替モデル間の同等性を保証していません。品質、速度、コスト、リージョン・プラン別可用性は別途検証が必要で、非推奨モデルの削除操作自体は不要です。
- **個別一次情報:** [GitHub Changelog — Selected models in GitHub Copilot deprecated](https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated/)

## 2. GitHub Security Advisory：機密コメントとREST／GraphQL APIを拡張

- **公開日:** 2026-10-02（GitHub Changelogの連動した3件）
- **タグ:** `data-engineering` `developer-tools` `security` `api`
- **日本語サマリ:** GitHubはrepository security advisoryに、write権限保持者だけが閲覧できる機密コメントを追加しました。同時に、通常コメントの取得・追加・編集をREST APIのpublic previewとして公開し、GraphQLのSecurityAdvisoryへCVE ID、該当ソース位置、GitHubレビュー日時、NVD公開日時、repository advisory URLと絞り込み条件を追加しました。
- **なぜ重要か:** 脆弱性報告の対外連絡、メンテナー内の調査メモ、監査・移行・自動トリアージをadvisory履歴の周辺へ集約できます。RESTとGraphQLの用途差を理解すれば、セキュリティデータ基盤の往復と認証経路も減らせます。
- **限界:** RESTコメントAPIはpublic previewで削除に未対応し、機密コメントを返しません。機密性はrepository権限に依存し、通常コメントとの相互変換もできません。監査ログ、token scope、権限変更後の可視性を含めた運用設計が必要です。
- **個別一次情報:** [REST comments API](https://github.blog/changelog/2026-10-02-repository-security-advisory-comments-api-in-public-preview/)、[Confidential comments](https://github.blog/changelog/2026-10-02-confidential-comments-on-repository-security-advisories/)、[GraphQL fields](https://github.blog/changelog/2026-10-02-new-fields-for-securityadvisory-graphql-api/)

## 3. PORTIA：港湾音響とAISを対応付けた船舶監視データセット

- **公開日:** 2026-10-02（Scientific Dataの出版版。データセットv2は2026-07-17）
- **タグ:** `data-science` `machine-learning` `dataset` `audio` `environmental-monitoring`
- **日本語サマリ:** PORTIAは、スペイン・バレンシア港で26日間収集した3秒音響窓260,932件を、同期したAIS船舶メタデータと対応付けたデータ記述です。二値検出36,148件、単一船舶分類39,125件、複数ラベル監視34,996件の三つのタスク向けsubsetを提供します。
- **なぜ重要か:** 実港湾の混雑・複数音源・距離変化を含む音響と船舶位置情報を再利用可能な形で公開し、船舶検出・船種分類・海洋騒音監視の比較評価を行いやすくしています。
- **限界:** 一つの港・26日間の固定観測に由来し、季節、港湾構造、センサー、船舶構成が異なる場所への一般化は未保証です。AISに載らない音源や同期・ラベル誤差も利用側で考慮する必要があります。
- **個別一次情報:** [Scientific Data — 原論文](https://www.nature.com/articles/s41597-026-08384-9)、[Zenodo — PORTIA Dataset v2](https://zenodo.org/records/21409381)。DOI: `10.1038/s41597-026-08384-9`

## 4. ブラジル医療データベース：MLで不確実なレコード対を自動分類

- **公開日:** 2026-10-02（Scientific Reportsの出版版）
- **タグ:** `data-science` `machine-learning` `data-engineering` `record-linkage` `healthcare`
- **日本語サマリ:** Lagesらは、ブラジル統一保健医療システムの四つの情報システムを対象に、multi-pass blocking後の不確実な候補対を教師ありMLで分類するTRAUMA linkageを検証しました。106,363件のラベル付き対で6手法を比較しLightGBMを採用、独立検証11,662件でROC-AUC 0.99988、F1 0.99252と報告しています。
- **なぜ重要か:** 組織横断の分析で負荷になりやすい個人レコード照合を、文字列類似度や生年月日などの特徴と説明可能性分析を用いて自動化し、手作業レビューの縮小可能性を示しました。
- **限界:** 検証はEspírito Santo州の2018年7月〜2025年6月データと、構築済みgold standardに依存します。著者もCIDACS-RLとの差を統計的優越性とはせず記述的比較としています。地域、欠損、表記慣行、プライバシー規則が異なる環境では再検証が必要です。
- **個別一次情報:** [Scientific Reports — 原論文](https://www.nature.com/articles/s41598-026-73928-3)。DOI: `10.1038/s41598-026-73928-3`

## 5. FuXi-Nowcast：3次元大気予報で強対流予測を条件付け

- **公開日:** 2026-10-02（npj Climate and Atmospheric Scienceの出版版。arXiv先行版は2025-12）
- **タグ:** `data-science` `machine-learning` `weather` `forecasting`
- **日本語サマリ:** FuXi-Nowcastは、高解像度観測と3次元大気予報を組み合わせ、合成レーダー反射強度、降水、突風、地表変数を最大12時間先まで予測する深層学習システムです。東中国の2024年4〜7月評価で、反射強度と降水について業務数値予報、持続、外挿の各baselineを上回ったと報告しています。
- **なぜ重要か:** 直近レーダーだけでは捉えにくい対流発生前の環境と、予測で弱まりやすい強いエコーの保持を明示的に扱い、短時間の画像外挿から環境条件付きの複数変数予測へ広げています。
- **限界:** 評価地域・季節は限定され、極端事例、警報運用、他地域の観測網で同じ技能を保証しません。出版社版の新規公開として採用しましたが、研究自体には2025年12月のarXiv先行版があります。
- **個別一次情報:** [npj Climate and Atmospheric Science — 原論文](https://www.nature.com/articles/s41612-026-01558-7)、[arXiv — 先行版](https://arxiv.org/abs/2512.08974)。DOI: `10.1038/s41612-026-01558-7`

- **タグ:** `data-science` `machine-learning` `materials-science` `automation`
- **日本語サマリ:** Zhaoらは、短鎖オクタン酸で前駆体反応性を調整する室温注入法と、自動合成・MLを組み合わせ、FAPbI₃ナノ結晶のサイズと分布を最適化しました。フロー合成へ拡張し、著者条件で製造費US$2.16/g、太陽電池の変換効率19.37%を報告しています。
