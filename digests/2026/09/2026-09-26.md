## 1. Databricks「Genie One MCP server」がGA
- **公開日:** 2026-09-25
- **タグ:** `generative-ai` `data-engineering` `agents` `analytics`
- **サマリ:** Databricks提供のMCP Service `system.ai.genie_one_mcp` が一般提供。Claude、ChatGPT、CursorなどのMCPクライアントから、Genie Oneを自然言語分析ツールとして利用でき、Unity Catalogの権限が各リクエストに適用されます。旧Betaエンドポイントは2026-10-31に終了予定です。

## 2. Genie Code、文書処理パイプラインをエンドツーエンドで構築
- **公開日:** 2026-09-25
- **タグ:** `generative-ai` `data-engineering` `developer-tools` `document-ai`
- **サマリ:** Genie CodeがPDF、契約書、請求書などを対象に、解析・分類・抽出・検証まで含む文書処理パイプラインを構築できるようになりました。ラベル付きデータに対して抽出品質を評価し、改善を反復します。

- **一次情報:** [Databricks — September 2026 release notes](https://docs.databricks.com/gcp/en/release-notes/product/2026/september)
- **詳細:** [Databricks — Use Genie Code for intelligent document processing](https://docs.databricks.com/aws/en/large-language-models/genie-code-document-processing)

## 3. Google Cloud Storage Intelligence advisorがGA、batch operationsも拡張
- **公開日:** 2026-09-25
- **タグ:** `data-engineering` `analytics` `cloud-ops`
- **サマリ:** Storage Intelligence advisorが一般提供され、ストレージ利用量・操作回数・429・クロスリージョン転送などの異常や最適化候補を自動検出。storage batch operationsは最大1,000バケットを横断する処理、dry-run、CELベースの高度なフィルタなどを追加しました。
- **なぜ重要か:** AI学習・推論や分析基盤で増えがちな大規模オブジェクトストレージを、独自集計パイプラインなしで観測し、検知から一括是正までつなげられます。
- **一次情報:** [Google Cloud — Storage Intelligence advisor: Know what changed in your storage estate and act on it](https://cloud.google.com/blog/products/storage-data-transfer/storage-intelligence-advisor-and-batch-operations-updates)
