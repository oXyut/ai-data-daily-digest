# AI & Data Daily Digest

生成AI・データサイエンス・機械学習・データエンジニアリング周辺のニュースや技術記事を、毎日収集・要約するリポジトリです。

## 方針
- 一次情報（公式ブログ、論文、リリース）を優先
- 同一ニュースの転載・類似記事は重複として除外
- 各項目に「要約」「なぜ重要か」「タグ」「出典」を付与
- 日次更新はPull Requestとして追加し、レビュー可能な形にする

## 構成
- `digests/YYYY/MM/YYYY-MM-DD.md`: 日次ダイジェスト
- `INDEX.md`: 掲載済み記事の時系列インデックス
- `tags/`: 分野別インデックス
